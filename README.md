# Node.js Cloudinary Image Upload

This is a Node.js application that uploads images to [Cloudinary](https://cloudinary.com/), a cloud-based media management service. It demonstrates how to use the Cloudinary SDK to store and manipulate images in the cloud.

## 📦 Features

- Upload local images to Cloudinary
- Environment variables for secure API key management

## 🛠️ Technologies Used

- Node.js
- Cloudinary SDK (`cloudinary`)
- `dotenv` for environment variable management
